## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cliente HTTP → backend Go | JWT + role admin; corpo/headers não confiáveis |
| backend Go → Oracle prod/PRODB | conexão síncrona nova (capacidade inédita D-03) usando credenciais cifradas |
| erp_bridge_config (at rest) → memória do processo | credenciais descriptografadas em runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Information Disclosure | openFiscalOracleConn / FiscalOraclePingHandler | mitigate | Nunca retornar err.Error() cru de sql.Open/Ping ao cliente; mensagens genéricas + log.Printf server-side (ASVS V5/V6) |
| T-11-02 | Elevation of Privilege | rota /api/fiscal/oracle-ping | mitigate | withAuth(handler, "admin") em main.go; guard 405 (método) e 401 (sem claims) no handler |
| T-11-03 | Denial of Service | pool Oracle dedicado | mitigate | SetMaxOpenConns(5) + PingContext com timeout 10s; conn.Close() em defer |
