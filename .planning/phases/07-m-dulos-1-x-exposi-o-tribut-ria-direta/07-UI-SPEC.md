## Spacing Scale

Declared values — Tailwind default 4px base scale; all values multiples of 4:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline gaps between label and icon |
| sm | 8px | Compact row padding, gap between label and input |
| md | 16px | Default element spacing, card content padding |
| lg | 24px | Section padding (CardContent `space-y-6`), gap between filter controls |
| xl | 32px | Layout gap between main sections on a page |
| 2xl | 48px | Major section breaks between module title and content |
| 3xl | 64px | Page-level vertical spacing (not used inside module cards) |

Exceptions:
- Touch targets for buttons: minimum 44px height (applies to all primary action buttons)
- Sensitivity table cells (Módulo 1.4): minimum 40px row height for readability of numeric matrix
- Disclaimer banners (Simples Nacional warning in Módulo 1.3): `py-3 px-4` (12px/16px) — slightly asymmetric for visual weight

Source: default Tailwind scale confirmed consistent with existing page patterns (ReformaParametros.tsx, ConciliacaoBridgeXML.tsx)

## Typography

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body | 14px (text-sm) | 400 (normal) | 1.5 | Inter |
| Label / mono / disclaimer | 12px (text-xs) | 600 (semibold) | 1.4 | Inter (labels); JetBrains Mono (numeric) |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 | Inter |
| Display | 28px (text-2xl) | 600 (semibold) | 1.2 | Inter |

Notes:
- Monetary values (R$ amounts in tables) use `font-mono text-xs` for alignment — JetBrains Mono is already loaded. Class: `text-xs font-mono`
- KPI metric values (large number callouts such as total float in Módulo 1.4) use 28px / semibold / Inter
- Table column headers use 12px (text-xs) / 600 (semibold), uppercase with `tracking-wide` — matches existing `TableHead` usage in ConciliacaoBridgeXML.tsx. Class: `text-xs font-semibold uppercase tracking-wide`
- Disclaimer text (regulatory notices) uses 12px (text-xs) / 400 (normal) / muted-foreground. Class: `text-xs text-muted-foreground`
- All numeric cell values in tables use `text-xs font-mono` regardless of whether they are monetary
- font-medium (500) is NOT used in this phase — only 400 (normal) and 600 (semibold)

Revision note: Font size scale consolidated from 5 sizes to 4 by merging former 12px (disclaimer/headers) and 13px (mono/numeric) into a single 12px size (text-xs). Font weights collapsed from 3 (400/500/600) to 2 (400/600) — all former font-medium (500) uses replaced with font-semibold (600). Applied 2026-05-22.

Source: existing component patterns verified in ReformaParametros.tsx and ConciliacaoBridgeXML.tsx

## Module-Specific Interaction Contracts

### Módulo 1.1 — Créditos ICMS Bloqueados (Reforma11CreditosBloqueados.tsx)

**Layout:** Single card with two sections — bar chart on top, sortable table below.

**Bar chart:** `BarChart` from recharts. X-axis: CFOP code (text-xs). Two bars per CFOP: "ICMS Bloqueado" (fill: `--pis-cofins` ≈ purple) and "Equiv. IBS+CBS" (fill: `--ibs-cbs` ≈ blue). `ResponsiveContainer` height: 280px. Show values on bar hover via recharts `Tooltip`. Legend below chart.

**Table columns:** Tipo CFOP | CFOP | ICMS Bloqueado (R$) | Valor Operação (R$) | IBS Equiv. (R$) | CBS Equiv. (R$) | Qtd Registros

**Numeric formatting:** All R$ values use `toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' })` — consistent with existing `fmtBRL()` pattern.

**Sorting:** Table sorted descending by ICMS Bloqueado by default (backend ORDER BY). No client-side sort controls needed for v1.

**Loading state:** Replace table body with 6 `Skeleton` rows (`h-8 w-full`).

**Empty state:** "Nenhum crédito ICMS encontrado para o período selecionado." — centered, text-sm text-muted-foreground, inside table area.

**KPI summary card (above main card):** 3 metrics in a row — `grid grid-cols-3 gap-4`. Metric: Total ICMS Bloqueado | Total Equiv. IBS | Total Equiv. CBS. Each uses `text-2xl font-semibold` (28px/600) with label at `text-sm text-muted-foreground`.

### Módulo 1.3 — Ranking Fornecedores (Reforma13RankingFornecedores.tsx)

**Layout:** Disclaimer banner + single card with bar chart + table.

**Disclaimer banner:** `Alert` with `AlertTriangle` icon, `variant="default"` with `border-warning text-warning-foreground bg-warning/10`. Copy: "Valores estimados. A alíquota definitiva do Fator Simples Nacional não foi publicada pelo CG-IBS. Use como referência indicativa." — this is the regulatory disclaimer required by RFMB-02.

**Bar chart:** Top 10 fornecedores by `ibs_perdido_est + cbs_perdido_est`. X-axis: shortened CNPJ or nome (max 12 chars, ellipsis). Single bar fill: `--ibs-cbs`. Height: 220px.

**Table columns:** # (rank) | CNPJ | Nome Fornecedor | Qtd Notas | Valor Total (R$) | IBS Estimado (R$) | CBS Estimado (R$) | Simples Nacional

**Simples Nacional column:** `Badge variant="warning"` with text "Simples" for confirmed Simples Nacional suppliers. Empty cell otherwise.

**CNPJ formatting:** Apply `fmtCNPJ()` function — pattern from existing ConciliacaoBridgeXML.tsx.

**Empty state:** "Nenhum fornecedor Simples Nacional encontrado. Verifique se a tabela forn_simples está populada." — centered, text-sm text-muted-foreground.

### Módulo 1.2 — Reprecificação por Produto (Reforma12Reprecificacao.tsx)

**Layout:** Single card with filter + table. No chart.

**Filters row:** `Select` for CST path (Todos / Normal (00) / Substituição Tributária / Base Reduzida). `Select` for period (mes_ano) if available from API.

**Table columns:** NCM | Descrição Produto | CST ICMS | Preço Atual (R$) | ICMS Atual (R$) | IBS Projetado (R$) | CBS Projetado (R$) | Variação (%)

**CST path badge:** In the CST ICMS column, render a `Badge` with variant: Normal → `secondary`, ST → `outline`, Base Reduzida → `default`. Font-mono for the 2-digit code.

**Variation column:** Positive variation (preço sobe) → `text-positive` (green). Negative variation → `text-negative` (red). Zero → `text-muted-foreground`. Prefix with "+" or "-" sign explicitly.

**Empty state:** "Nenhum produto encontrado. Verifique se há notas fiscais de entrada importadas."

**Note on NULL values:** Rows with NULL `cst_icms` are shown with CST badge "—" in muted-foreground and IBS/CBS columns showing "—". Do not hide these rows — they represent historical data without CST info.

### Módulo 1.4 — Split Payment / Capital de Giro (Reforma14SplitPayment.tsx)

**Layout:** 2 KPI cards + sensitivity matrix table. No bar chart.

**KPI cards (top row):** `grid grid-cols-2 gap-4`. Card 1: "Float Tributário" — value in R$ at text-2xl font-semibold. Card 2: "Custo CDI Estimado (R$/ano)" — value in R$ at text-2xl font-semibold. Each card has a subtitle line in text-sm text-muted-foreground showing the formula basis: "IBS+CBS × Saídas × X dias / 365".

**Sensitivity matrix:** Card with title "Tabela de Sensibilidade — DSO × CDI". Table: rows = DSO values (15, 30, 45, 60, 90 dias); columns = CDI values (8%, 10%, 12%, 14%). Cell values = custo CDI in R$. Use `font-mono text-xs` for all numeric cells. Highlight the current DSO/CDI combination (from `reforma_parametros`) with `bg-primary/10 font-semibold`.

**Disclaimer banner:** `Alert variant="default"` below KPIs. Copy: "Split payment entra em vigor gradualmente entre 2026 e 2033 conforme cronograma da Reforma. Os valores simulam o impacto no regime de transição plena." Icon: `Info`.

**Empty state (no saídas data):** "Nenhuma nota fiscal de saída encontrada. Os módulos de split payment requerem dados de NF-e de saída importados via XML."

## State Machine Contract

Each module page has 4 states. Use this mapping:

| State | Trigger | UI Treatment |
|-------|---------|-------------|
| Loading | `isLoading === true` from useQuery | Hide table/chart; show Skeleton rows (6 rows, `h-8 w-full`) inside Card |
| Error | `isError === true` | Show `Alert variant="destructive"` with error message inside Card; hide table/chart |
| Empty | `data` is defined but array length is 0 | Show centered empty state copy (text-sm text-muted-foreground) inside table area; show CSV button disabled |
| Data | Array length > 0 | Render full table + chart; CSV button enabled |

CSV export button state:
- `variant="outline"` when data is empty or loading
- `variant="default"` (primary — blue) when data is available

## Accessibility Contract

- All table headers use `scope="col"` attribute (via shadcn TableHead which renders `<th>`)
- Bar charts include `aria-label` on the `ResponsiveContainer` wrapper: `aria-label="Gráfico de créditos ICMS bloqueados por CFOP"`
- Tooltip triggers use `asChild` with a visible trigger element (not invisible div)
- Alert banners include `role="alert"` (built into shadcn Alert component)
- CSV buttons use descriptive `aria-label`: `aria-label="Exportar tabela de créditos como CSV"`
- Sensitivity matrix cells (Module 1.4): highlighted cell uses `aria-current="true"` in addition to background color
- Disabled navigation tabs: `aria-disabled="true"` + `tabIndex={-1}` (already handled by shadcn disabled prop on Tab)
