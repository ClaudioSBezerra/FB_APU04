**2. Refatorar as 3 páginas de upload (substituir a UI de seleção de pasta por drag-and-drop):**

Cada página (ImportarXMLsEntrada, ImportarXMLsSaida, ImportarXMLsCTe) deve implementar:

**Estado local:**
- uploadState: 'idle' | 'uploading' | 'polling' | 'done' | 'error'
- batchId: string | null
- uploadResult: { imported, rejected, total, errorDetails } | null
- progress: number (0..100 durante polling)

**Zona de drop (react-dropzone):**
```tsx
const { getRootProps, getInputProps, isDragActive } = useDropzone({
  accept: {
    'text/xml': ['.xml'],
    'application/zip': ['.zip'],
    'application/x-zip-compressed': ['.zip'],
  },
  maxSize: 100 * 1024 * 1024,
  multiple: true,
  onDropRejected: (rejected) => {
    toast.error(`${rejected.length} arquivo(s) rejeitados. Apenas XML e ZIP até 100MB.`)
  },
  onDrop: handleUpload,
})
```

A zona de drop deve ter styling visual claro: borda dashed quando idle, borda azul e fundo azul claro quando isDragActive. Ícone de upload + texto "Arraste XMLs ou ZIP aqui, ou clique para selecionar".

**handleUpload(files: File[]):**
- setUploadState('uploading')
- Para cada arquivo (ou para o conjunto), criar FormData com campo "tipo" (entradas/saidas/ctes) e "file"
- POST /api/xml/upload via fetchAuth
- Se resposta 200: mostrar resultado inline, setUploadState('done')
- Se resposta 202: setUploadState('polling'), setBatchId(data.batch_id)
- Se erro: toast.error com mensagem do backend (413 → "Arquivo excede 100MB"), setUploadState('error')

**Barra de progresso durante polling:**
```tsx
const { data: batchStatus } = useQuery({
  queryKey: ['xml-batch', batchId],
  queryFn: () => fetchAuth(`/api/xml/upload-batches/${batchId}/status`).then(r => r.json()),
  enabled: !!batchId && uploadState === 'polling',
  refetchInterval: uploadState === 'polling' ? 2000 : false,
})
```
Calcular progress = Math.round((batchStatus?.processed_count / batchStatus?.total_count) * 100) || 0.
Usar Progress component do Radix UI (já instalado).
Quando batchStatus.status === 'done': toast.success com contagens, setUploadState('done').
Quando batchStatus.status === 'failed': toast.error, setUploadState('error').

**Seção de histórico de uploads:**
```tsx
const { data: historico } = useQuery({
  queryKey: ['xml-historico', tipo],
  queryFn: () => fetchAuth(`/api/xml/upload-batches?tipo=${tipo}&limit=10`).then(r => r.json()),
  refetchInterval: uploadState === 'polling' ? 3000 : false,
})
```
Tabela com colunas: Data, Arquivo, Tipo, Total, Importados, Rejeitados, Status, Usuário.
Status como Badge: done → verde, processing → azul, failed → vermelho, pending → cinza.

Diferenças entre as 3 páginas: apenas o valor do parâmetro "tipo" (entradas/saidas/ctes) e os textos da UI.

CONVENÇÃO: não setar cabeçalhos manualmente — fetchAuth injeta automaticamente. Sem console.log em produção.
