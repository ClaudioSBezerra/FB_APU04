**XMLSaneamentoCCLASSTRIBHandler** — GET /api/xml/reports/saneamento (per D-16a):
Query: NCMs com variação de CST entre diferentes fornecedores para a mesma empresa.
```sql
SELECT
    ei.ncm,
    COUNT(DISTINCT ei.cst_pis)    AS variantes_cst_pis,
    COUNT(DISTINCT ei.cst_cofins) AS variantes_cst_cofins,
    COUNT(DISTINCT ei.cclasstrib) FILTER (WHERE ei.cclasstrib IS NOT NULL) AS variantes_cclasstrib,
    BOOL_OR(ei.cclasstrib IS NULL) AS tem_cclasstrib_nulo,
    COUNT(*) AS qtd_itens,
    SUM(ei.v_pis)    AS v_pis_total,
    SUM(ei.v_cofins) AS v_cofins_total,
    -- Listar os CSTs distintos para diagnóstico
    array_agg(DISTINCT ei.cst_pis)    FILTER (WHERE ei.cst_pis IS NOT NULL) AS csts_pis,
    array_agg(DISTINCT ei.cst_cofins) FILTER (WHERE ei.cst_cofins IS NOT NULL) AS csts_cofins
FROM nfe_entradas_itens ei
WHERE ei.company_id = $1
GROUP BY ei.ncm
HAVING COUNT(DISTINCT ei.cst_pis) > 1
    OR COUNT(DISTINCT ei.cst_cofins) > 1
    OR BOOL_OR(ei.cclasstrib IS NULL)
ORDER BY qtd_itens DESC
LIMIT 500;
```
Parâmetros query string: mes_ano (formato YYYY-MM, opcional — filtrar via JOIN com nfe_entradas.mes_ano).
Retornar JSON array de objetos: {ncm, variantes_cst_pis, variantes_cst_cofins, variantes_cclasstrib, tem_cclasstrib_nulo, qtd_itens, v_pis_total, v_cofins_total, csts_pis, csts_cofins}.

**XMLSaneamentoCSVHandler** — GET /api/xml/reports/saneamento/csv (per D-16b):
Mesma query do relatório de saneamento, mas serializada como CSV.
Usar encoding/csv da stdlib para gerar o CSV:
```go
w.Header().Set("Content-Type", "text/csv; charset=utf-8")
w.Header().Set("Content-Disposition", `attachment; filename="saneamento-cclasstrib.csv"`)
csv.NewWriter(w).WriteAll(rows) // cada row: []string{ncm, variantes_cst_pis, ..., sugestao_cclasstrib}
```
Incluir coluna "sugestao_cclasstrib" vazia no CSV — o contador do escritório preenche manualmente e reimporta para atualizar o cadastro.
Incluir cabeçalho em PT-BR: NCM, Variantes CST PIS, Variantes CST COFINS, CCLASSTRIB Ausente, Qtd Itens, V. PIS Total, V. COFINS Total, CSTs PIS Encontrados, CSTs COFINS Encontrados, Sugestão CCLASSTRIB.

**XMLFornecedoresCCLASSTRIBHandler** — GET /api/xml/reports/fornecedores-cclasstrib (per D-16c):
Fornecedores cujas notas têm itens com cclasstrib NULL ou com múltiplas classificações para o mesmo NCM:
```sql
SELECT
    ne.forn_cnpj,
    ne.forn_nome,
    ei.ncm,
    COUNT(*) FILTER (WHERE ei.cclasstrib IS NULL) AS itens_sem_cclasstrib,
    COUNT(DISTINCT ei.cclasstrib) FILTER (WHERE ei.cclasstrib IS NOT NULL) AS variantes_cclasstrib,
    SUM(ei.v_pis + ei.v_cofins) AS v_pis_cofins_total
FROM nfe_entradas_itens ei
JOIN nfe_entradas ne ON ne.id = ei.nfe_id
WHERE ei.company_id = $1
GROUP BY ne.forn_cnpj, ne.forn_nome, ei.ncm
HAVING COUNT(*) FILTER (WHERE ei.cclasstrib IS NULL) > 0
    OR COUNT(DISTINCT ei.cclasstrib) FILTER (WHERE ei.cclasstrib IS NOT NULL) > 1
ORDER BY v_pis_cofins_total DESC
LIMIT 200;
```
Retornar JSON array: {forn_cnpj, forn_nome, ncm, itens_sem_cclasstrib, variantes_cclasstrib, v_pis_cofins_total}.
