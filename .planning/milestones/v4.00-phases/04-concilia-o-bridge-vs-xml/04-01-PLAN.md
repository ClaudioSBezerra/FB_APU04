<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → ConciliacaoHandler | query params mes_ano e tipo chegam sem validação prévia |
| ConciliacaoHandler → nfe_entradas/nfe_saidas | nome de tabela derivado do param tipo |
| ConciliacaoCSVHandler → response stream | dados fiscais sensíveis enviados como download |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01-01 | Tampering | param tipo → nome de tabela | mitigate | Whitelist explícita: tabela := "nfe_entradas"; if tipo == "saidas" { tabela = "nfe_saidas" } — nenhum outro valor é aceito; nome nunca concatenado como input bruto |
| T-04-01-02 | Tampering | param mes_ano → SQL | mitigate | mes_ano passado como $2 parametrizado via args slice — nunca interpolado na string SQL |
| T-04-01-03 | Information Disclosure | IDOR — ver dados de outra empresa | mitigate | GetEffectiveCompanyID valida relação user↔company; WHERE company_id = $1 parametrizado em todas as queries |
| T-04-01-04 | Denial of Service | query sem LIMIT retorna volume ilimitado | mitigate | LIMIT 500 na query de divergência; LIMIT 24 na de cobertura |
| T-04-01-05 | Information Disclosure | CSV export de outra empresa | mitigate | ConciliacaoCSVHandler usa GetEffectiveCompanyID identicamente ao JSON handler — mesmo isolamento |
| T-04-01-06 | Spoofing | request sem JWT | mitigate | ClaimsKey assert + jsonErr 401 no início de todos os handlers, antes de qualquer acesso a DB |
</threat_model>
